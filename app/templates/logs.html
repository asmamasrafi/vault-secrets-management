Bonnes pratiques

Security best practices

Consulter les journaux

Exécute cette commande dans PowerShell, depuis le dossier du projet, pour consulter les dernières lignes des logs Flask : 

docker compose logs --tail=50 app

Pour suivre les nouveaux événements en temps réel : 

docker compose logs -f app
⚠️ Conseil de sécurité
Cette page explique comment consulter les logs, mais ne les expose pas directement dans le navigateur. Cela évite de rendre des informations internes accessibles aux visiteurs de l’application.
