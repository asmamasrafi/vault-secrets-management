✧   Vue d'ensemble

Cette application démontre comment HashiCorp Vault gère les secrets d'une application Flask connectée à PostgreSQL. Les identifiants sont récupérés depuis Vault au moment du test, plutôt que d'être codés en dur dans le code Python.

🛡️
Secrets Centralisés dans Vault
🐳
Docker Services isolés
🔐
AppRole Authentification
⚡
API Vérification rapide

Comment fonctionne le système ?

1Flask s'authentifie auprès de Vault via AppRole.
2Vault fournit le secret de connexion autorisé.
3Flask teste la connexion à PostgreSQL.
4Le dashboard affiche le résultat du test.
